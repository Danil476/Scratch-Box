# 🧪 Scratch-Box

**Scratch-Box** — это фановый проект, который эмулирует простую виртуальную машину. Внутри неё можно «открывать» различные вирусы и наблюдать за их забавным и совершенно безопасным поведением в изолированной среде.

Проект создан на Scratch и упакован через **TurboWarp Packager**, поэтому распространяется как готовое приложение — без необходимости устанавливать Scratch.

> ⚠️ **Важно:** Это исключительно симуляция. Проект не содержит реального вредоносного кода и не представляет угрозы для вашего компьютера. Все «вирусы» — это безопасные анимации, звуки и визуальные эффекты.

## ✨ Особенности

- **Эмуляция виртуальной машины:** простой интерфейс, имитирующий рабочую среду.
- **Коллекция «вирусов»:** несколько разных вирусов, каждый со своим уникальным поведением.
- **Полная безопасность:** все действия происходят внутри программы, поэтому можно смело экспериментировать.
- **Готовые сборки:** проект запускается как отдельное приложение под разные ОС благодаря TurboWarp Packager.

## 📥 Скачать и запустить (релиз 1.1 Beta 1)

1. Перейдите в раздел **Releases** и откройте тег **[1.1_Beta-1](https://github.com/Danil476/Scratch-Box/releases/tag/1.1_Beta-1)**.
2. Скачайте файл, подходящий для вашей операционной системы.
3. Запустите программу.

> ℹ️ **Обратите внимание на типы файлов:**
> * **`Scratch-Box_HTML.html`** — это **один файл**, в который уже встроены все спрайты и звуки. Просто откройте его в браузере, ничего распаковывать не нужно.
> * **`HTML-ZIP`** (архив с HTML-версией) — здесь `index.html` лежит отдельно от папок со спрайтами и другими ресурсами. **Обязательно полностью распакуйте архив** в одну папку и запускайте `index.html` оттуда. Не удаляйте и не перемещайте файлы по отдельности, иначе игра не найдет ресурсы!
> * **Сборки для Windows и Linux (ZIP)** — также требуют полной распаковки с сохранением структуры папок (включая папку со спрайтами).
> * **Сборка для macOS (`OSX.zip`)** — просто распакуйте архив и запустите приложение `.app`. Внутри macOS все нужные ресурсы (спрайты) уже упакованы в сам файл приложения, поэтому вам не нужно беспокоиться об их отдельном сохранении.

## 💻 Поддержка устройств по сборкам в Releases

В релизе доступны следующие файлы. Поддерживаемые устройства зависят от архитектуры вашего процессора и ОС:

| Файл в релизе | Поддерживаемые устройства и ОС | Как запустить |
| :--- | :--- | :--- |
| **`Scratch-Box_HTML.html`** | Любые устройства (ПК, ноутбуки, Android, iOS) | Открыть файл в современном браузере (всё в одном файле) |
| **`HTML-ZIP` (архив)** | Любые устройства (ПК, ноутбуки, Android, iOS) | Полностью распаковать ZIP и открыть `index.html` в браузере |
| **`Scratch-Box_WIN64.zip`** | Windows 10 / 11 (64-bit) | Полностью распаковать ZIP и запустить `.exe` файл |
| **`Scratch-Box_WIN32.zip`** | Windows 7 / 8 / 10 / 11 (32-bit) | Полностью распаковать ZIP и запустить `.exe` файл |
| **`Scratch-Box_WIN-ARM.zip`** | Windows на ARM-процессорах | Полностью распаковать ZIP и запустить `.exe` файл |
| **`Scratch-Box_OSX.zip`** | macOS (Intel и Apple Silicon / M1/M2/M3) | Распаковать ZIP и запустить приложение `.app` |
| **`Scratch-Box_LINUX64.zip`** | Linux (x86_64 / 64-bit) | Полностью распаковать ZIP и запустить исполняемый файл |
| **`Scratch-Box_LINUX_ARM-64.zip`** | Linux на ARM (64-bit) | Полностью распаковать ZIP и запустить исполняемый файл |
| **`Scratch-Box_LINUX_ARM-32.zip`** | Linux на ARM (32-bit) | Полностью распаковать ZIP и запустить исполняемый файл |

> ℹ️ Если вы не уверены в разрядности своей системы или не хотите возиться с архивами, используйте **`Scratch-Box_HTML.html`** — это универсальный одиночный файл, который работает везде, где есть браузер.

## 🎮 Как играть

1. Запустите приложение (или откройте HTML-файл).
2. Нажмите зелёный флажок или кнопку старта, чтобы запустить «виртуальную машину».
3. Взаимодействуйте с объектами на сцене, чтобы «открыть» тот или иной вирус.
4. Наблюдайте за результатом — от забавной анимации до неожиданного звукового эффекта.

## 🛠️ Как это работает

Программа имитирует поведение виртуальной машины: «вирусы» активируются при взаимодействии с ними и запускают различные визуальные и звуковые эффекты. Всё происходит в изолированной фановой среде и не влияет на вашу систему.
