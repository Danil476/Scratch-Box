# 🧪 Scratch-Box

**Scratch-Box** — это фановый проект, который эмулирует простую виртуальную машину. Внутри неё можно «открывать» различные вирусы и наблюдать за их забавным и совершенно безопасным поведением в изолированной среде.

Проект создан на Scratch и упакован через **TurboWarp Packager**, поэтому распространяется как готовая программа — без необходимости что-то собирать или запускать через Scratch.

> ⚠️ **Важно:** Это исключительно симуляция. Проект не содержит реального вредоносного кода и не представляет угрозы для вашего компьютера. Все «вирусы» — это безопасные анимации, звуки и визуальные эффекты.

## ✨ Особенности

- **Эмуляция виртуальной машины:** простой интерфейс, имитирующий рабочую среду.
- **Коллекция «вирусов»:** несколько разных вирусов, каждый со своим уникальным поведением.
- **Полная безопасность:** все действия происходят внутри программы, поэтому можно смело экспериментировать.
- **Готовая сборка:** запускается как отдельное приложение благодаря TurboWarp Packager.

## 📥 Скачать и запустить

1. Перейдите в раздел **Releases** этого репозитория.
2. Скачайте сборку, подходящую для вашего устройства.
3. Запустите файл — и «виртуальная машина» готова к работе.

## 💻 Поддержка устройств по сборкам Releases

Поддерживаемые устройства зависят от конкретной сборки, опубликованной в **Releases**. Ниже — ориентир по типу файлов:

| Тип сборки | Поддерживаемые устройства | Как запустить |
|---|---|---|
| **Windows `.exe`** | Windows 10/11 (x64) | Скачать `.exe` и запустить |
| **HTML5-сборка** | ПК, ноутбуки, Android и iOS | Открыть в современном браузере (Chrome, Edge, Firefox, Safari) |
| **macOS `.app` / `.dmg`** | macOS (Intel / Apple Silicon), если сборка добавлена в Releases | Открыть `.dmg` и перетащить приложение в Applications |
| **Linux `.AppImage` / `.deb`** | Linux x64, если сборка добавлена в Releases | Сделать файл исполняемым и запустить |

> ℹ️ Если в **Releases** нет сборки для вашей системы, используйте HTML5-версию в браузере. На старых версиях ОС и браузеров работа не гарантируется.

## 🎮 Как играть

1. Запустите программу.
2. Нажмите зелёный флажок или кнопку старта, чтобы запустить «виртуальную машину».
3. Взаимодействуйте с объектами на сцене, чтобы «открыть» тот или иной вирус.
4. Наблюдайте за результатом — от забавной анимации до неожиданного звукового эффекта.

## 🛠️ Как это работает

Программа имитирует поведение виртуальной машины: «вирусы» активируются при взаимодействии с ними и запускают различные визуальные и звуковые эффекты. Всё происходит в изолированной фановой среде и не влияет на систему.
